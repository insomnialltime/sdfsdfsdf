# Flo+ — полный гайд от А до Я

Это подробная инструкция для человека, который не программирует, но хочет
самостоятельно запустить своего Telegram-бота с приложением Flo+.
Читай по порядку, ничего не пропускай — и всё получится.

---

## Что вообще происходит

У тебя есть три вещи, которые работают вместе:

1. **Бот в Telegram** — с ним можно написать `/start`, он присылает кнопку
   «Открыть Flo».
2. **Веб-приложение (вебапп)** — то, что открывается внутри Telegram, когда
   ты нажимаешь на кнопку. Это календарь, заметки, статистика и всё
   остальное, что ты видишь на экране.
3. **Сервер** — компьютер (может быть твой собственный ноутбук на время
   тестов или облачный сервер для постоянной работы), на котором всё это
   крутится: и бот, и вебапп, и база данных с твоими записями.

Всё это лежит в одной папке с проектом, которую тебе выдал разработчик
(или которую ты скачала из этого чата).

---

## Что нового появилось в этой версии (Flo+)

По сравнению с базовой версией добавлено:

- **Экран «Сегодня»** — приветствие, цитата дня, дневник настроения и
  симптомов, заметка о дне, трекер воды, дыхательная пауза 4-7-8.
- **Улучшенный календарь цикла** — теперь показывает не только месячные,
  но и предполагаемую овуляцию и фертильное окно.
- **Статистика** — средняя длина цикла, регулярность, самые частые
  симптомы за 90 дней, график веса.
- **Заметки с категориями** — «Общее», «Здоровье», «К врачу», «Идеи», можно
  закреплять важные заметки.
- **Настройки** — цель по воде в мл, выбор темы оформления (светлая,
  тёмная, как в Telegram).
- **Новая цветовая палитра** — пудровая роза, лаванда и шалфей вместо
  простого розового.

Всё это уже готово в коде — тебе нужно только правильно всё запустить.

## Шаг 1. Установи нужные программы на компьютер

### 1.1. Python

Заходи на сайт [python.org/downloads](https://www.python.org/downloads/)
и скачай последнюю версию Python (подойдёт версия 3.11 или новее).

При установке на Windows обязательно поставь галочку **«Add python.exe to
PATH»** внизу окна установщика — это важно, без этого дальнейшие шаги не
сработают.

Проверить, что всё установилось: открой «Командную строку» (Windows) или
«Терминал» (Mac) и напиши:

```
python --version
```

Если видишь что-то вроде `Python 3.12.4` — всё хорошо.

### 1.2. Редактор кода (по желанию, но удобно)

Скачай [Visual Studio Code](https://code.visualstudio.com/) — бесплатный
редактор, в котором удобно смотреть и при необходимости слегка менять
файлы проекта.

## Шаг 2. Создай бота в Telegram

1. Открой Telegram и найди бота **@BotFather** (это официальный бот от
   самого Telegram для создания других ботов).
2. Напиши ему команду `/newbot`.
3. Он спросит имя бота — придумай любое, например `Flo Plus`.
4. Затем спросит username — он обязательно должен заканчиваться на `bot`,
   например `flo_plus_health_bot`.
5. BotFather пришлёт тебе **токен** — длинную строку вида
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.

**Это очень важная строка — никому её не показывай.** Она как пароль от
твоего бота. Сохрани её куда-нибудь (например, в заметки на телефоне).

### 2.1. Включи кнопку меню (по желанию)

В BotFather можно ещё:
- `/setdescription` — написать описание бота.
- `/setuserpic` — поставить аватарку.

Это не обязательно для работы, просто для красоты.

## Шаг 3. Получи адрес для вебаппа (HTTPS-ссылка)

Telegram требует, чтобы вебапп открывался по адресу, начинающемуся с
`https://` (обычный `http://` не подойдёт). Для тестов проще всего
использовать бесплатный сервис **ngrok**, который временно «пробрасывает»
твой компьютер в интернет.

### 3.1. Установи ngrok

1. Зайди на [ngrok.com](https://ngrok.com/) и зарегистрируйся бесплатно.
2. Скачай ngrok для своей операционной системы.
3. После установки на сайте ngrok будет команда вида:
   ```
   ngrok config add-authtoken ТВОЙ_ТОКЕН
   ```
   Выполни её в терминале один раз.

Позже, когда сервер будет запущен на порту 8000, ты откроешь **второе**
окно терминала и наберёшь:

```
ngrok http 8000
```

Ngrok покажет строку вида `https://abcd-1234.ngrok-free.app` — это и есть
твой `WEBAPP_URL`, о котором речь пойдёт ниже.

> Для постоянной, «боевой» работы бота (а не только для тестов) лучше
> в будущем арендовать облачный сервер (например, VPS) с настоящим
> доменом и SSL-сертификатом — но для начала и обучения ngrok отлично
> подходит.

## Шаг 4. Настрой файл .env

В папке проекта есть файл `.env.example`. Это шаблон настроек.

1. Скопируй файл `.env.example` и переименуй копию в `.env` (без
   расширения `.example`).
2. Открой `.env` в блокноте или VS Code и впиши туда свои данные:

```
BOT_TOKEN=123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
WEBAPP_URL=https://abcd-1234.ngrok-free.app
PORT=8000
```

- `BOT_TOKEN` — токен, который дал BotFather.
- `WEBAPP_URL` — ссылка, которую показал ngrok (пункт 3.1). Если ты
  перезапустишь ngrok, ссылка изменится — не забудь обновить её здесь.
- `PORT` — можно оставить 8000, если этот порт свободен на компьютере.

Сохрани файл.

## Шаг 5. Установи зависимости проекта

Открой терминал/командную строку, перейди в папку проекта командой `cd`
(например: `cd Documents/flo-project`), и выполни:

```
pip install -r requirements.txt
```

Эта команда скачает и установит все библиотеки Python, которые нужны
проекту (FastAPI, aiogram, aiosqlite и так далее). Подожди, пока всё
скачается — обычно это занимает 1–3 минуты.

Если команда `pip` не находится — попробуй `pip3` или `python -m pip
install -r requirements.txt`.

## Шаг 6. Запусти проект

В той же папке в терминале выполни:

```
python main.py
```

Если всё хорошо, ты увидишь примерно такие строки:

```
База данных готова.
Планировщик напоминаний запущен.
Сервер запускается на порту 8000...
Бот запускается...
```

Это значит, что:
- база данных `flo.db` создалась автоматически рядом с проектом;
- бот начал «слушать» сообщения в Telegram;
- сервер начал раздавать вебапп на `http://localhost:8000`.

**Не закрывай это окно терминала** — пока оно открыто, бот работает. Как
только закроешь — бот выключится.

---

## Шаг 7. Запусти ngrok (второе окно терминала)

Открой **новое** окно терминала (первое не трогай — там работает бот) и
выполни:

```
ngrok http 8000
```

Скопируй адрес `https://...ngrok-free.app`, который появится в
терминале, и убедись, что именно он записан в `.env` в переменной
`WEBAPP_URL`. Если ты вписывала другой адрес до запуска ngrok — сохрани
правильный в `.env`, останови бота (`Ctrl+C` в первом окне) и запусти
`python main.py` заново, чтобы он подхватил новый адрес.

## Шаг 8. Проверь, что всё работает

1. Найди своего бота в Telegram по username, который ты придумала в
   BotFather.
2. Напиши `/start`.
3. Бот пришлёт приветствие и кнопку **«Открыть Flo»**.
4. Нажми на кнопку — должно открыться приложение с розово-лавандовым
   дизайном, экраном «Сегодня» и нижним меню из пяти вкладок.

Если приложение не открывается или показывает ошибку — смотри раздел
«Возможные проблемы» в конце этого гайда.

## Шаг 9. Как пользоваться приложением

### 🌷 Вкладка «Сегодня»
- Наверху — приветствие и цитата дня.
- Карточка с фазой цикла и советом, подходящим именно для этой фазы.
- Выбери своё настроение (эмодзи), отметь симптомы чипсами, при желании
  напиши заметку о дне и нажми «Сохранить».
- Ниже — трекер воды: нажимай +200 / +300 / +500, чтобы отметить, сколько
  выпила. «Сброс» обнуляет счётчик на сегодня.
- Кнопка «Начать паузу» открывает дыхательное упражнение 4-7-8: нажми на
  круг и дыши вместе с его расширением и сжатием.

### 🌸 Вкладка «Цикл»
- Календарь: нажимай на дни, чтобы отметить месячные (розовым).
- Жёлтым отмечается предполагаемая овуляция, светло-зелёным — фертильное
  окно, пунктирной обводкой — прогноз следующих месячных.
- Шестерёнка сверху открывает настройки цикла (длина цикла, длина
  месячных, дата последнего начала).

### 📝 Вкладка «Заметки»
- Кнопка ➕ создаёт новую заметку с категорией (Общее / Здоровье / К
  врачу / Идеи).
- Можно поставить напоминание — в указанное время бот пришлёт сообщение
  прямо в чат.
- Значок 📌 закрепляет важную заметку наверху списка.
- Вкладки-чипы сверху фильтруют заметки по категориям.

### 📊 Вкладка «Статистика»
- Средняя длина цикла и его регулярность считаются автоматически по
  отмеченным в календаре дням месячных.
- Самые частые симптомы за последние 90 дней (данные берутся из вкладки
  «Сегодня»).
- Трекер веса: впиши число и нажми «Добавить» — появится столбик на
  графике.

### ⚙️ Вкладка «Ещё»
- Быстрый доступ к напоминаниям и настройкам цикла.
- Цель по воде в мл в день (по умолчанию 2000).
- Выбор темы: как в Telegram, светлая или тёмная.

## Как это работает «под капотом» (простыми словами)

- Все твои данные хранятся в одном файле `flo.db` рядом с проектом. Это
  маленькая база данных SQLite — по сути, просто файл на диске, ничего
  дополнительно устанавливать не нужно.
- Когда ты нажимаешь любую кнопку в приложении (сохранить заметку,
  отметить день, добавить воду), вебапп посылает запрос на сервер
  (`api.py`), а сервер читает или записывает данные в `flo.db` через
  `database.py`.
- Каждый такой запрос проверяется функцией из `security.py` — она
  удостоверяется, что запрос действительно пришёл из Telegram именно от
  тебя, а не от постороннего человека, который угадал адрес сайта.
- Отдельная программа-«будильник» (`scheduler.py`) каждые 30 секунд
  проверяет: не наступило ли время для одного из напоминаний. Если да —
  бот присылает тебе сообщение в чат.

## Как остановить и снова запустить бота

- Чтобы **остановить**: перейди в окно терминала, где выполняется
  `python main.py`, и нажми `Ctrl+C`.
- Чтобы **запустить снова**: набери `python main.py` в папке проекта. Все
  твои старые данные (заметки, отметки цикла и т.д.) сохранятся — они
  лежат в файле `flo.db` и никуда не пропадают между запусками.

## Возможные проблемы и решения

**«Не найден BOT_TOKEN» при запуске**
Значит, файл `.env` не создан или в нём опечатка. Проверь, что файл
называется именно `.env` (без `.example` на конце) и лежит в той же
папке, что и `main.py`.

**Кнопка «Открыть Flo» не реагирует / показывает белый экран**
Скорее всего, `WEBAPP_URL` в `.env` не совпадает с текущим адресом
ngrok (он меняется при каждом перезапуске ngrok на бесплатном тарифе).
Скопируй актуальный адрес из окна ngrok, обнови `.env`, перезапусти
`python main.py`.

**«ModuleNotFoundError: No module named ...»**
Значит, не установились зависимости. Снова выполни
`pip install -r requirements.txt` в папке проекта.

**Напоминания не приходят**
Убедись, что окно с `python main.py` всё ещё открыто и работает — бот
присылает напоминания, только пока сервер запущен. Также проверь, что
при создании заметки было указано будущее время (не в прошлом).

**После перезапуска ngrok приложение снова не открывается**
Бесплатный ngrok при каждом перезапуске выдаёт новую ссылку. Не забывай
обновлять `WEBAPP_URL` в `.env` после каждого перезапуска ngrok и снова
запускать `python main.py`.

## Что дальше, если хочешь запустить это «навсегда»

Ngrok отлично подходит для тестов, но требует, чтобы твой компьютер и
терминал были постоянно включены. Для круглосуточной работы бота обычно
арендуют недорогой облачный сервер (VPS) у любого хостинг-провайдера,
устанавливают туда Python и этот же проект, и настраивают постоянный
домен вместо временной ngrok-ссылки. Это уже более техническая задача —
если понадобится, можно обсудить отдельно, какой вариант хостинга выбрать
именно под твой случай.

---

Если что-то не получается на каком-то шаге — не переживай, это нормально
для первого раза. Внимательно перечитай нужный шаг ещё раз, проверь, что
не пропустила ни одной буквы в файле `.env`, и попробуй снова. 🌸
