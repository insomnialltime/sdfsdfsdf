# Flo Telegram WebApp — туториал от А до Я (без лишнего)

Здесь всё расписано так, чтобы просто копировать команды одну за
другой. Никаких "разберись сам" — если что-то непонятно на любом
шаге, просто напиши мне номер шага, разберём.

Идём строго по порядку, ничего не пропускаем.

---

## Шаг 1. Создаём бота

1. Открой Telegram, в поиске набери `BotFather`, открой чат с ним
   (у него синяя галочка подтверждённого аккаунта).
2. Напиши ему: `/newbot`
3. Он спросит имя бота — напиши любое, например: `Flo Tracker`
4. Он спросит username — напиши то, что заканчивается на `bot`,
   например: `flo_tracker_777_bot` (если занято — придумай другой).
5. Он пришлёт сообщение с токеном. Выглядит примерно так:
   `7123456789:AAHk3jd82jdKSKDsjkd82jdkJHDKSJD`
   Скопируй этот токен и вставь куда-нибудь в заметки — он ещё
   понадобится в шаге 4. Никому его не показывай.

---

## Шаг 2. Устанавливаем Python

Открой терминал:
- **Windows**: нажми Win, набери `PowerShell`, открой
- **Mac**: нажми Cmd+Пробел, набери `Terminal`, открой

Введи команду:

```bash
python3 --version
```

Если видишь что-то вроде `Python 3.11.6` — Python уже есть, переходи
к шагу 3.

Если видишь ошибку "команда не найдена" — качай Python отсюда:
https://www.python.org/downloads/

При установке на Windows **обязательно** поставь галочку
**"Add Python.exe to PATH"** внизу окна установщика — без неё ничего
не заработает. После установки закрой и открой терминал заново,
проверь команду ещё раз.

---

## Шаг 3. Скачиваем проект

Распакуй архив `flo-app.zip`, который я тебе прислал, в удобное
место, например на рабочий стол. Дальше в терминале переходим
в эту папку. Замени путь на свой:

```bash
cd Desktop/flo-app
```

Проверь, что ты внутри папки — введи:

```bash
ls
```
(на Windows: `dir`)

Ты должен увидеть список файлов: `main.py`, `bot.py`, `api.py` и т.д.
Если список пуст или ошибка — значит ты не в той папке, проверь путь.

---

## Шаг 4. Устанавливаем нужные библиотеки

Прямо в этой же папке выполни:

```bash
pip3 install -r requirements.txt
```

(если `pip3` не находится — попробуй просто `pip install -r requirements.txt`)

Подожди, пока всё скачается — там будет много строк в консоли,
это нормально. В конце должно быть что-то вроде
`Successfully installed aiogram-3.15.0 fastapi-0.115.6 ...`

---

## Шаг 5. Вставляем токен

1. В папке `flo-app` найди файл `.env.example`.
2. Сделай его копию и назови копию `.env` (точка в начале обязательна,
   без расширения .txt в конце).

   В терминале это делается одной командой:
   ```bash
   cp .env.example .env
   ```
   (на Windows: `copy .env.example .env`)

3. Открой файл `.env` в блокноте (или через `notepad .env` на Windows,
   `open -e .env` на Mac) и замени содержимое на:

```
BOT_TOKEN=вставь_сюда_свой_токен_из_шага_1
WEBAPP_URL=https://placeholder.example
PORT=8000
```

4. Сохрани файл. Строку `WEBAPP_URL` мы заполним правильным значением
   в шаге 7 — пока оставь как есть.

---

## Шаг 6. Запускаем бота первый раз (проверка)

В терминале, находясь в папке `flo-app`, введи:

```bash
python3 main.py
```

Ты должен увидеть:
```
База данных готова.
Планировщик напоминаний запущен.
Сервер запускается на порту 8000...
```

Если вместо этого красная ошибка — смотри раздел "Ошибки" в самом
низу этого файла, там есть решение почти для любой ошибки на этом шаге.

Если всё ок — **не закрывай** это окно терминала, бот должен
оставаться запущенным. Переходи к следующему шагу в **новом** окне
терминала.

---

## Шаг 7. Делаем вебапп доступным по https (через ngrok)

Telegram открывает мини-приложения только по адресу, начинающемуся
на `https://`. Пока у тебя нет своего сайта, используем ngrok —
он бесплатно и быстро даёт такой адрес для тестирования.

1. Зайди на https://ngrok.com, зарегистрируйся (можно через Google).
2. После регистрации на главной странице личного кабинета будет
   раздел **"Install and Authenticate"** с готовыми командами.
   Тебе там дадут команду вида:
   ```bash
   ngrok config add-authtoken твой_личный_код
   ```
   Скачай ngrok там же (кнопка Download) и выполни эту команду
   в терминале один раз.

3. Открой **новое** окно терминала (не закрывая то, где работает бот),
   перейди в любую папку и запусти:

```bash
ngrok http 8000
```

4. Появится текст вроде:
```
Session Status    online
Forwarding        https://a1b2-34-56-78-90.ngrok-free.app -> http://localhost:8000
```

Скопируй адрес, который начинается на `https://` и заканчивается на
`ngrok-free.app` (у тебя он будет свой, другой).

5. Открой файл `.env` снова, замени строку `WEBAPP_URL` на этот адрес:
```
WEBAPP_URL=https://a1b2-34-56-78-90.ngrok-free.app
```
Сохрани файл.

6. Вернись в окно терминала, где запущен `main.py`, нажми `Ctrl+C`,
   чтобы остановить его, и запусти заново:
```bash
python3 main.py
```
(это нужно, чтобы бот подхватил новый адрес из `.env`)

7. Теперь идём в Telegram, снова открываем чат с **BotFather**:
   - напиши `/mybots`
   - выбери своего бота из списка
   - нажми **Bot Settings**
   - нажми **Menu Button**
   - нажми **Configure Menu Button**
   - пришли туда тот же адрес: `https://a1b2-34-56-78-90.ngrok-free.app`
   - когда спросит текст кнопки — напиши, например, `Открыть Flo`

Готово, вебапп подключен к боту.

---

## Шаг 8. Проверяем, что реально всё работает

1. В Telegram найди своего бота по username (тот, что придумал в шаге 1).
2. Нажми **Start**.
3. Должно прийти сообщение с кнопкой "🌸 Открыть Flo".
4. Нажми на кнопку — откроется приложение с розовым календарём.
5. Нажми на шестерёнку ⚙️ вверху, укажи сегодняшнюю дату как дату
   последних месячных, нажми Сохранить.
6. Вернись на главный экран — должен появиться текст "День цикла: 1".
7. Перейди на вкладку "Заметки" (иконка 📝 снизу), нажми ➕.
8. Введи заголовок, например "Тест", в поле "Напомнить об этом"
   поставь время на 2 минуты вперёд от текущего момента, нажми
   "Сохранить заметку".
9. Не закрывай Telegram, подожди 2-3 минуты — должно прийти сообщение
   от бота "🔔 Напоминание: Тест".

Если пришло — всё настроено правильно, можно переходить к постоянному
хостингу (Шаг 9), чтобы это работало без твоего компьютера.

## Шаг 9. Хостинг — чтобы бот работал 24/7 без твоего компьютера

Сейчас бот работает, только пока у тебя открыт терминал и включён
компьютер. Чтобы он работал постоянно (как настоящий сервис),
разместим его на **Railway** — это самый простой вариант для новичка,
бесплатного тарифа хватит для одного бота.

### 9.1. Заливаем проект на GitHub

1. Зайди на https://github.com, зарегистрируйся, если нет аккаунта.
2. Нажми зелёную кнопку **New** (или "+" в правом верхнем углу →
   **New repository**).
3. Название репозитория: `flo-app`. Остальное не трогай.
   Нажми **Create repository**.
4. GitHub покажет страницу с командами. Тебе нужны команды из блока
   **"…or push an existing repository from the command line"**.
   Но перед этим — важно: создай файл `.gitignore`, чтобы случайно
   не залить токен в открытый доступ. В нашем проекте он уже есть
   (файл `.gitignore` в папке `flo-app`), проверять ничего не надо.

5. В терминале, находясь в папке `flo-app`, выполни по очереди:

```bash
git init
git add .
git commit -m "Первая версия Flo"
git branch -M main
git remote add origin https://github.com/ТВОЙ_НИКНЕЙМ/flo-app.git
git push -u origin main
```

Замени `ТВОЙ_НИКНЕЙМ` на свой ник на GitHub (он написан в адресе
той страницы, которую тебе показал GitHub на шаге 3).

Если `git` не установлен — терминал предложит установить его
(на Mac) или скачай отсюда: https://git-scm.com/downloads

Если попросит логин/пароль от GitHub — вместо пароля нужен **Personal
Access Token**. Создать его: зайди на https://github.com/settings/tokens
→ **Generate new token (classic)** → поставь галочку **repo** →
**Generate token** → скопируй полученный код и вставь его вместо
пароля, когда терминал попросит.

### 9.2. Разворачиваем на Railway

1. Зайди на https://railway.app, нажми **Login**, войди через GitHub
   (это проще всего — не потребует отдельной регистрации).
2. На главной странице нажми **New Project**.
3. Выбери **Deploy from GitHub repo**.
4. Если Railway попросит доступ к твоим репозиториям — нажми
   **Configure GitHub App** и разреши доступ к репозиторию `flo-app`.
5. Выбери из списка репозиторий `flo-app`. Railway начнёт деплой
   автоматически — не переживай, что он пока упадёт с ошибкой, это
   нормально, мы ещё не задали переменные окружения.
6. Нажми на созданный сервис (прямоугольник с названием `flo-app`).
7. Перейди на вкладку **Variables**.
8. Нажми **New Variable** и добавь по одной:
   - `BOT_TOKEN` = твой токен из шага 1
   - `WEBAPP_URL` = пока оставь `https://placeholder.example`
     (обновим через минуту)
   - `PORT` = `8000`
9. Перейди на вкладку **Settings**, найди раздел **Networking**,
   нажми **Generate Domain**. Railway выдаст тебе публичный адрес
   вида `https://flo-app-production-xxxx.up.railway.app`.
10. Скопируй этот адрес, вернись на вкладку **Variables**, отредактируй
    `WEBAPP_URL`, вставь туда этот адрес (с `https://`, без слэша на конце).
11. Railway автоматически пересоберёт и перезапустит проект после
    сохранения переменных (следи за вкладкой **Deployments** — там
    должен появиться зелёный статус **Success**).

### 9.3. Финальная настройка бота

1. Останови ngrok и локальный `python3 main.py` — они больше не
   нужны, теперь всё работает на Railway.
2. Иди в **BotFather** → `/mybots` → выбери бота → **Bot Settings**
   → **Menu Button** → **Configure Menu Button** → пришли туда
   адрес с Railway из шага 9.2.9 (`https://flo-app-production-xxxx.up.railway.app`).
3. Открой бота в Telegram, нажми **Start**, проверь, что кнопка
   открывает приложение так же, как в Шаге 8. Теперь это работает
   даже если твой компьютер выключен.

**Важно:** каждый раз, когда меняешь код проекта на своём компьютере
и хочешь обновить версию на Railway, выполняй в папке `flo-app`:
```bash
git add .
git commit -m "Описание изменений"
git push
```
Railway сам увидит изменения на GitHub и передеплоит проект.

## Как устроен код — коротко

```
flo-app/
├── main.py       — запускает бота + сервер + напоминалку вместе
├── config.py      — читает BOT_TOKEN, WEBAPP_URL, PORT из .env
├── database.py     — всё чтение/запись в SQLite (файл flo.db)
├── security.py      — проверяет, что запрос реально пришёл из Telegram
├── api.py             — отдаёт вебапп и обрабатывает запросы от него
├── bot.py               — команда /start и кнопка "Открыть Flo"
├── scheduler.py           — раз в 30 секунд проверяет напоминания
└── webapp/
    ├── index.html          — разметка приложения (3 экрана)
    ├── style.css             — розовый дизайн
    └── app.js                  — вся логика: календарь, заметки, запросы
```

Каждый файл в архиве уже содержит подробные комментарии на русском —
открой любой файл, наверху есть объяснение, зачем он нужен.

## Ошибки и решения

**`ModuleNotFoundError: No module named 'aiogram'`**
→ Ты не выполнил Шаг 4 (`pip3 install -r requirements.txt`) в той же
папке, где лежит `main.py`. Проверь командой `ls`, что ты в папке
`flo-app`, и повтори установку.

**`RuntimeError: Не найден BOT_TOKEN`**
→ Файл `.env` не создан, лежит не в папке `flo-app`, либо в нём
опечатка в слове `BOT_TOKEN`. Открой `.env` и сверь построчно
с примером из Шага 5.

**Бот не отвечает на /start**
→ Убедись, что окно терминала с `python3 main.py` всё ещё открыто
и не показывает красных ошибок. Проверь, что токен скопирован
без лишнего пробела в начале или конце.

**Кнопка есть, но при нажатии белый экран / ничего не открывается**
→ Обычно значит, что `WEBAPP_URL` в `.env` не совпадает с адресом,
который вписан в BotFather (Menu Button), либо ngrok/Railway
адрес "протух" (перезапустился и поменялся). Проверь, что оба
адреса — в `.env` и в BotFather — идентичны, и что сервер запущен.

**401 Unauthorized при любом действии в приложении**
→ Значит вебапп открыт не через Telegram (например, ты вставил
адрес прямо в браузер). Тестировать можно только через кнопку
у бота внутри Telegram.

**Напоминание не пришло**
→ Проверь, что бот запущен именно через `main.py` (не `api.py`
отдельно) — планировщик стартует только внутри `main.py`. Также
убедись, что указанное время напоминания ещё не прошло на момент
создания заметки.

**На Railway деплой падает с ошибкой**
→ Открой вкладку **Deployments** → нажми на неудачный деплой →
посмотри лог. Обычно причина — не заданы переменные `BOT_TOKEN`
или `WEBAPP_URL` (Шаг 9.2.8). Пришли мне текст ошибки из лога —
разберём вместе.
